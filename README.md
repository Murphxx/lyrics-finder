# 🎵 Lyrics Finder

Modern ve kullanıcı dostu bir şarkı sözü arama uygulaması. Sanatçı ve şarkı adını girerek istediğiniz şarkının sözlerine kolayca ulaşabilirsiniz.

## ✨ Özellikler

- 🎨 Modern ve şık kullanıcı arayüzü
- 🌓 Karanlık/Aydınlık mod desteği
- 🔍 Hızlı ve kolay arama
- 📱 Mobil uyumlu tasarım
- 📋 Son aramaları kaydetme
- ⚡ Yükleme animasyonları

## 🚀 Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/Murphxx/lyrics-finder.git
```

2. Proje dizinine gidin:
```bash
cd lyrics-finder
```

3. `index.html` dosyasını bir web tarayıcısında açın.

## 💻 Kullanım

1. Sanatçı adını girin
2. Şarkı adını girin
3. "Find Lyrics" butonuna tıklayın
4. Şarkı sözleri otomatik olarak yüklenecektir

## 🛠️ Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6+)
- [Font Awesome](https://fontawesome.com/) - İkonlar için
- [Lyrics.ovh API](https://lyrics.ovh) - Şarkı sözleri için

## 🌟 Özellikler Detayı

### Karanlık Mod
- Sağ üst köşedeki tema değiştirme butonu ile karanlık/aydınlık mod arasında geçiş yapabilirsiniz
- Tema tercihiniz tarayıcınızda saklanır

### Son Aramalar
- Son 5 aramanız otomatik olarak kaydedilir
- Kaydedilen aramalara tıklayarak hızlıca tekrar arama yapabilirsiniz

### Responsive Tasarım
- Tüm ekran boyutlarına uyumlu
- Mobil cihazlarda optimize edilmiş görünüm
